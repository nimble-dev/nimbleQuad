Choosing Quadrature in nimbleQuad

Paul van Dam-Bates

Introduction

The nimbleQuad package has two main components:

  1. Adaptive Gauss-Hermite Quadrature (AGHQ) for marginalizing over latent nodes (e.g. random effects) to preform maximum likelihood estimation (buildLaplace if nQuad = 1) and buldAGHQ otherwise.
  2. Quadrature methods for posterior approximation using Laplace for inner marginalization of latent nodes, and more general quadrature tools for outer marginalization buildNestedApprox.

Here we will review some of the custom control available when using buildNestedApprox for posterior approximations.

library(nimbleQuad)

Using nimbleQuad

To write this model in NIMBLE we need to first write a zero-inflated Poisson distribution that marginalizes over the the zeros and counts. We need to marginalize as the parameters in the model must be continuous in order to use automatic differentiation to perform the nested posterior approximation. To allow for AD in a nimbleFunction we must set buildDerivs = 'run' in this case. A random number generator is also provided for convenience, although this is not strictly needed for this model to function.

dZIP <- nimbleFunction(
 run = function(x = double(), lambda = double(),
                zeroProb = double(), log = logical(0, default = 0)) {
   returnType(double())
   ## For use with AD, we cannot use an `if` statement to handle the mixture.
   prob <- zeroProb * dbinom(x, size = 1, prob = 0) + (1 - zeroProb) * dpois(x, lambda)
   if (log) return(log(prob))
     return(prob)
   },
   buildDerivs = 'run'   # Needed when used with AD-based algorithms.
)

rZIP <- nimbleFunction(
 run = function(n = integer(), lambda = double(), zeroProb = double()) {
   returnType(double())
   isStructuralZero <- rbinom(1, prob = zeroProb, size = 1)
   if (isStructuralZero) return(0)
   return(rpois(1, lambda))
})

Now we will use prior distributions to math the INLA function that was fit above. See inla.priors.used(fit.inla) for a description of all the default priors used.

## NIMBLE Model Code
code <- nimbleCode({
  beta[1] ~ dflat()
  for( i in 2:np ) 
    beta[i] ~ dnorm(0, tau = 0.001) 
  tau_re ~ dgamma(shape = 1, rate = 5e-5)
  logitp ~ dnorm(mean = -1, tau = 0.2)
  p <- expit(logitp)
  
  for(i in 1:nsites) 
    re[i] ~ dnorm(0, tau = tau_re)

  for( i in 1:nobs ){
    log(lam[i]) <- sum(beta[1:np]*X[i,1:np]) + re[site[i]]
    count[i] ~ dZIP(lambda = lam[i], zeroProb = p)
  }
})

nimconst <- list()
nimconst$X <- as.matrix(model.matrix( ~ spp * mined, data = Salamanders ))
nimconst$np <- ncol(nimconst$X)
nimconst$nobs <- nrow(nimconst$X)
nimconst$site <- as.numeric(factor(Salamanders$site))
nimconst$nsites <- max(nimconst$site)

nimdata <- list()
nimdata$count <- Salamanders$count

inits <- list(logitp = -0.9, 
  tau_re = 3,
  re = rnorm(nimconst$nsites,0,0.1),
  beta = rnorm(nimconst$np))

m <- nimbleModel(code, data = nimdata, constants = nimconst, inits = inits, buildDerivs = TRUE)
cm <- compileNimble(m)
